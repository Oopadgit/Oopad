# Star Portal Integration

Owner explicitly approved label, size, click, disabled and loading adaptations
for all Oopad controls on October 1, 2026. Star Portal is the selected variant.

`ShaderButtonSystem` decorates native controls without replacing handlers,
accessible names, types, form ownership or trusted wallet clicks. The exact
authored `.holo-btn` material and hover are applied through the host stylesheet.
Size/shape/state adapters keep icon controls compact and asset rows readable.

`document.ts` parses the immutable Imaginie source, copies its complete main
script verbatim and isolates its two original canvases. Inert demo headline
targets remain because the authored script also animates those elements. The
unrelated demo media, remote scripts, fonts and marketing markup are not loaded.
Opaque allow-scripts-only frames are inert artwork, never an action bridge.

Each visible enabled control owns one Canvas 2D frame. Hidden/offscreen/disabled
controls release their entire frame. This variant uses no WebGL contexts.
Reduced motion schedules no animation frames. Host DPR supplies backing density
because Chromium can expose DPR 1 inside opaque srcDoc during device emulation.
Logical coordinates and authored particle counts, movement, colors and drawing
functions are unchanged. ResizeObserver waits for actual frame dimensions.

The separate `ShaderButtons` public entry retains the original seven variants
and ten Pro studies through lazy first-party modules, plus their mode and final
palette controls. Only an explicitly selected study mounts while visible. These
unused studies are not requested by the application and were not newly visually
validated. Do not interpret their presence as app-wide use or verification.

## Provenance

`sources/manifest.json` records URLs, HTTP status, bytes and SHA-256 for every
downloaded artifact. The public repository lacks RakingLightPillButton.tsx,
SelectedButtonStudies.tsx and button-index.html at this check. First-party site
modules retain their compiled implementations; the selected-studies HTML is
decoded without rewriting it. The advertised aggregate revision 6f56c4f91814
has no published hash recipe and is not falsely claimed as a verified local
aggregate. Per-file downloaded hashes are regression tested.

`scripts/prepare-shader-family.mjs` changes only the React import boundary of
archived modules; tests compare the entire resulting module body. Raw source
files are never manually edited. Do not rerun the download script as an
unreviewed automatic upgrade. The original archive and app adaptation are
different artifacts. Attribution is also served at /threeui-notice.txt.
